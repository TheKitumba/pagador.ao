# 12 — Glossário

| Termo | Definição |
| --- | --- |
| **Abono de família** | Prestação atribuída ao trabalhador em função dos dependentes a cargo. |
| **Acerto final de contas** | Cálculo de todos os créditos e débitos entre trabalhador e empresa na cessação do contrato. |
| **Adenda** | Alteração formal a um contrato de trabalho já existente. |
| **AGT** | Administração Geral Tributária — entidade responsável pela cobrança de impostos em Angola. |
| **Ajudas de custo** | Montantes pagos para compensar despesas do trabalhador em deslocação em serviço. |
| **Antiguidade** | Tempo de serviço do trabalhador na empresa, relevante para indemnizações, diuturnidades e férias. |
| **APD** | Agência de Protecção de Dados — autoridade de controlo da protecção de dados pessoais. |
| **Aviso prévio** | Antecedência mínima com que uma das partes deve comunicar a cessação do contrato. |
| **Banco de horas** | Regime em que as horas a mais são compensadas com tempo de descanso, em vez de pagas. |
| **BI** | Bilhete de Identidade — documento de identificação de cidadãos angolanos. |
| **BNA** | Banco Nacional de Angola — banco central; publica as taxas de câmbio de referência. |
| **Caducidade** | Cessação automática do contrato por verificação de um facto (fim do termo, reforma, morte). |
| **Centro de custo** | Unidade contabilística à qual se imputam os custos com pessoal. |
| **Convenção colectiva** | Acordo entre empregadores e sindicatos que define condições de trabalho, podendo melhorar as condições legais mínimas. |
| **Diuturnidade** | Acréscimo remuneratório por cada período de antiguidade. |
| **EMIS** | Empresa Interbancária de Serviços — gere a rede Multicaixa e os sistemas de pagamentos interbancários. |
| **Encargo patronal** | Custo suportado pela entidade empregadora para além do salário (ex.: 8% de Segurança Social). |
| **Entidade empregadora** | Pessoa singular ou colectiva que contrata trabalhadores. |
| **EPI** | Equipamento de Protecção Individual. |
| **Escalão** | Intervalo de rendimento ao qual se aplica uma taxa de IRT; também nível de uma tabela salarial. |
| **Expatriado** | Trabalhador estrangeiro não residente colocado em Angola. |
| **Folha de pagamento** | Conjunto dos recibos e valores processados para os trabalhadores num período. |
| **Folha de remunerações** | Declaração mensal ao INSS com as remunerações e contribuições de cada trabalhador. |
| **Gratificação de fim de ano / subsídio de Natal** | Prestação anual paga até Dezembro. |
| **IGT** | Inspecção Geral do Trabalho — fiscaliza o cumprimento da legislação laboral. |
| **Ilíquido** | Valor bruto da remuneração antes de descontos. |
| **INSS** | Instituto Nacional de Segurança Social. |
| **IRT** | Imposto sobre os Rendimentos do Trabalho. |
| **LGT** | Lei Geral do Trabalho (Lei n.º 12/23, de 27 de Dezembro). |
| **Líquido** | Valor que o trabalhador efectivamente recebe após descontos. |
| **Matéria colectável** | Valor sobre o qual se aplica a tabela de IRT, depois de deduzidos os rendimentos isentos e a contribuição do trabalhador para a Segurança Social. |
| **Mecanográfico (n.º)** | Número interno de identificação do trabalhador na empresa. |
| **Modelo 2** | Declaração anual de rendimentos do trabalho dependente entregue à AGT. |
| **NIF** | Número de Identificação Fiscal. |
| **OGE** | Orçamento Geral do Estado — aprovado anualmente; pode alterar regras fiscais. |
| **Penhora** | Desconto no salário ordenado por tribunal para pagamento de uma dívida. |
| **Período experimental** | Período inicial do contrato durante o qual qualquer das partes pode fazer cessar o contrato sem indemnização. |
| **PGC** | Plano Geral de Contabilidade de Angola. |
| **Pré-folha** | Simulação do cálculo da folha antes do processamento definitivo. |
| **Processamento** | Execução do cálculo salarial para um período e tipo (normal, férias, Natal, etc.). |
| **Proporcionais** | Partes de férias e subsídios devidos em função do tempo de serviço no ano. |
| **Rasto de cálculo** | Registo que explica como cada valor de um recibo foi obtido. |
| **Recibo de vencimento** | Documento entregue ao trabalhador com o detalhe da remuneração e dos descontos. |
| **Retenção na fonte** | Desconto do imposto pela entidade empregadora no momento do pagamento. |
| **Retroactivos** | Diferenças salariais relativas a meses anteriores, pagas num período posterior. |
| **Rotação (regime de)** | Alternância de períodos de trabalho e de folga (ex.: 28 dias de trabalho por 28 de folga). |
| **Rubrica** | Linha de vencimento, desconto ou encargo na folha de pagamento. |
| **SAF-T (AO)** | Ficheiro normalizado de auditoria tributária adoptado pela AGT. |
| **Salário mínimo nacional** | Remuneração mínima obrigatória fixada por Decreto Presidencial. |
| **Segurança Social** | Sistema de protecção social obrigatória; contribuições de 3% (trabalhador) e 8% (empresa) por omissão. |
| **Subsídio de férias** | Prestação paga em função do período de férias, de pelo menos 50% do salário base. |
| **Tenant** | Conta de cliente isolada no sistema multi-inquilino. |
| **Vencimento base** | Parte fixa da remuneração, definida no contrato. |
